# Nagara（ながら）

**作業しながら、動画見ながら、ゲームしながら — でも音楽の操作はいつも同じ場所へ。**

[English README](README.en.md)

Nagara は、キーボードのメディアキー（再生／停止・次へ・前へ）の送り先を固定できる、macOS / Windows 向けの常駐フリーソフトです。

## 解決する問題

メディアキーは通常「最後にメディアを掴んだアプリ」に流れるため、Spotify で音楽を聴きながらブラウザで動画を開いていると、止めたい方と違うアプリが操作されてしまいます。Nagara はメディアキーの送り先を自分で選んで固定し、この取り合いをなくします。

## 主な機能（v0.1 予定）

- メディアキーの送り先を固定：Spotify / 音楽アプリ / 自動（再生中のアプリ）
- メニューバー（macOS）／タスクトレイ（Windows）からワンクリックで送り先を切替
- ログイン時起動の ON / OFF
- 多言語対応：日本語 / 英語（OS 言語に追従、手動切替も可）
- 通信なし・テレメトリなし。設定はローカルにのみ保存されます

## 対応環境

- macOS（開発中）
- Windows（開発中）
