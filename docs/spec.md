# Nagara（ながら）仕様ドラフト — メディアキー振り分けユーティリティ

- 作成日: 2026-10-29
- 位置づけ: レイノワークスのフリーソフト枠（単体アプリ）。集客・認知の入口として無料公開し、有料製品（Megrab Studio / HomeRoute Switcher）への導線にする。
- キャッチコピー（2026-10-29 採用決定）: 「作業しながら、動画見ながら、ゲームしながら — でも音楽の操作はいつも同じ場所へ。」配布ページ・紹介文の冒頭に使う。
- きっかけ: マルチメディアキーを押すとアクティブなアプリ（Spotifyとブラウザ等）が取り合いになり、意図しない方が操作される問題。既存の解決ツールは海外製ばかりで、日本語対応の軽い選択肢がほぼない（2026-10-29調査）。

## 解く問題
- macOS / Windows とも、メディアキー（再生/停止・次へ・前へ）は「最後にメディアセッションを掴んだアプリ」に流れ、ユーザーが固定できない。
- ブラウザ（YouTube等）がキーを横取りして、バックグラウンドのSpotifyを止めたいのに動画が止まる、等が頻発する。

## 競合（いずれも海外製）
- Mac: Mac Media Key Forwarder（フォーク版が現行）、MediaPrimeKey、BeardedSpice（ブラウザ対象）
- Windows: 専用アプリは乏しく、ブラウザの Hardware Media Key Handling フラグ無効化＋AutoHotkey が事実上の workaround

## v0.1 MVP（想定）
- 対応OS: macOS と Windows（着手順は HomeRoute と同じく Mac 先行→Windows を想定、要検討）
- 常駐アプリ（Mac: メニューバー / Windows: タスクトレイ）
- メディアキーの送り先を以下から選んで固定できる:
  - Spotify
  - Apple Music（Mac）/ 既定の音楽アプリ（Windows）
  - 自動（再生中のアプリへ。OS標準動作に近い）
- トレイ/メニューバーからワンクリックで送り先を切替
- ログイン時起動のON/OFF
- 設定はローカル保存のみ。通信なし、テレメトリなし（フリーソフトの信頼感を優先）

## 多言語対応（優先事項、2026-10-29決定）
- Nagara は最初から多言語対応を優先する（Megrab の「日本語先行・英語は後から」とは逆の方針）。理由: フリーソフト＋OSS の拡散先は全世界で、海外製ツールへの対抗軸が「日本発・多言語」になるため。
- v0.1 から UI 文字列をコードに直書きせず、リソース化する（Mac: String Catalog / .strings、Windows: resx 等）。
- 対応言語 v0.1: 日本語・英語。言語設定は「OSに追従（自動）」＋手動切替。
- README は日本語版と英語版を用意する。

## 技術メモ
- Mac: イベントタップでメディアキーを横取りし、対象アプリへ AppleScript / Now Playing 経由で指示。要アクセシビリティ許可 + オートメーション許可。macOS 26/27 での動作検証が必須（競合フォークも Tahoe 対応を掲げている）。
- Windows: 低レベルキーボードフックで VK_MEDIA_* を横取りし、対象アプリへ送信。ブラウザは SMTC で奪いに来るため、横取り側が優先されるよう実装する。Spotify はウィンドウメッセージ/メディアキー再送で制御可能。
- 対象外（v0.1）: 音量キーの振り分け、ブラウザ内タブ単位の制御（BeardedSpice領域）、Bluetoothイヤホンのボタン制御。
